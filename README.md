# forever-fishing

Помощник для рыбалки в World of Warcraft. Слушает звук игры. Когда поплавок плеснул, жмёт клавишу подсечки, а потом снова закидывает удочку.

> **Автоматизация нарушает правила Blizzard, за неё могут забанить.** Пользуйся на свой риск и не оставляй игру без присмотра.

## Скачать

Готовый `forever-fishing.exe` лежит в [Releases](https://github.com/poznik/forever-fishing/releases). Это один файл, ставить ничего не нужно. Работает на Windows 10/11 x64.

Exe не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажми «Подробнее», потом «Выполнить в любом случае».

## Как это работает

- Слушает звук, который идёт на устройство вывода по умолчанию (WASAPI loopback).
- Поклёвкой считается звук громче порога (−40 dB), который к тому же на 10 dB громче фона.
- После поклёвки: пауза 0.5–1.5 с, клавиша подсечки, пауза 1–2.5 с, клавиша заброса.
- Если поклёвки нет 22 с, утилита перезабрасывает.
- Клавиши уходят прямо в окно WoW, поэтому игра может быть неактивной: можно сидеть в другом окне.

## Настройка игры (один раз)

1. **Звук.** Выключи музыку и звуки окружения, эффекты оставь. Включи «Звук в фоновом режиме», иначе неактивный WoW молчит.
2. **Управление.** «Рыбная ловля» на `U`, «Взаимодействие с целью» на `Y`. Можно назначить свои клавиши и поменять их в окне утилиты.
3. **Графика.** Поставь «Макс. частота кадров в фоне» не меньше 30, чтобы игра быстро реагировала.
4. **Пока рыбачишь**, выключи звук у YouTube, Discord и прочего: утилита слышит весь звук системы.

## Как пользоваться

1. Запусти `forever-fishing.exe`. Окно откроется на паузе.
2. Встань у воды лицом к ней.
3. Нажми `Ctrl+Shift+Y`, это работает из любого окна. Высокий писк значит старт, низкий — пауза. Кнопка в окне делает то же самое.

В окне можно поменять клавиши, паузы (вида `1-2.5`), порог и галочку «Работать с неактивным окном WoW». Новые значения применяются при следующем старте и сохраняются в `fishbot.json` рядом с exe.

Как подобрать порог: в окне есть индикатор громкости, белая черта на нём — порог. Всплеск поплавка должен заходить за черту, а фон — нет.

## Если что-то не так

- **Персонаж не реагирует на клавиши.** Если WoW запущен от администратора, запусти exe тоже от администратора. Ещё можно снять галочку неактивного окна и держать WoW активным.
- **Ложные поклёвки.** Подними порог, например до `-35`.
- **Пропускает поклёвки.** Опусти порог, например до `-45`, и проверь по индикатору.
- **Ругается антивирус.** Exe, собранные PyInstaller, часто дают ложное срабатывание. Можно собрать exe самому, инструкция ниже.

## Сборка из исходников

Нужен Python 3.13.

```powershell
pip install -r requirements.txt pyinstaller
powershell -ExecutionPolicy Bypass -File build.ps1
```

Готовый файл появится в `dist\forever-fishing.exe`.

Окно можно запустить и без сборки: `pythonw fishbot_gui.pyw`. Для консольного режима и калибровки есть отдельные команды:

```powershell
python fishbot.py --calibrate      # уровень звука, ничего не нажимает
python fishbot.py --background     # рыбалка из консоли, F10 - пауза, F12 - выход
python fishbot.py --help           # все параметры
```
